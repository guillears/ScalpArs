- ☐ Master pool: archive the batch (scripts/build_master_pool.py); re-run scripts/screen_pool.py if the stack changed
- ☐ Sleeve ORDER by stake: SPIKE_FADE → WILLY + WILLY_HT → FLATBASE → LITE / FRENZY_LONG → momentum long → momentum short → FAN flips → Bear-Run / SURGE / rest
- ☐ ONE SLEEVE AT A TIME (operator 2026-10-26): ① master batch before → after per batch · ② current batch before → after · ③ backtest before → after · ④ the quant recommendation (a clear call per watchlist item) · ⑤ STOP for the operator's OK before the next sleeve; new strategies: winners vs losers FIRST, then exits; momentum longs: W/L on the full master
- ☐ Every table carries the three blocks (current batch · master per batch · backtest), presented master → batch → backtest (the sleeve order above); before → after per batch; say whether a candidate ADDS or REMOVES a filter
- ☐ Before → after on TODAY's stack (re-simulate first); in-sample results labelled + 30–50 % haircut; market-wide effects in DAY units; per-pair / per-day concentration; the backtest refutes, never proves alone
- ☐ Classify every watchlist item: DECIDED by its frozen gate · OPERATOR CALL below the bar (say so) · KEEP OBSERVING (count + expected date)
- ☐ After all sleeves: PORTFOLIO view (shared slots, concurrent exposure, worst day, drawdown, sleeve overlap) → one-page decisions list + go-live criteria; ship ONE change at a time (risk-first; size/filter apart from exits)
- ☐ Operator-closed (MANUAL / MANUAL_* / EXTERNAL_CLOSE) fills excluded from every gate (scout_gatekit)
- ☐ Learnings box per sleeve first (plan §0a) · freeze predicted separators before reading (§0a+) · bug gate: two independent derivations + an independent reviewer agent on any recommendation (§0c)
- ☐ Run the full opportunity scout (scripts/opportunity_scout.py) AND every standalone scout; re-run tick-first scouts once the aggTrades archives publish (≥ 6 h after the day ends)
- ☐ Any 'no separator' / sleeve-kill claim → scripts/sweep_separators.py output first (CLAUDE.md sleeve-kill checklist)
