## Method (four independent reads, each sleeve apart, full-size only)
- **① RAW master** = every master fill of the sleeve with the post-hoc fitted blocks IGNORED (watch-line filters DL 527–561, pair blacklists, fade / Bull-Run / momentum gate re-scopes). Removed only: probes, MANUAL, switched-off sleeves (SPIKE_BOUNCE / CHASE / WIDE / SURGE_SHORT OFF) and Bull-Run v1. Kept fills use stack_pct (today's exit); blocked fills have no re-price → their as-traded % (older exits — understates sleeves whose exit later improved: WILLY V2b, LITE +3). The BASE era was pre-screened by SCREENED_BASELINE, so ① is still not perfectly raw.
- **"fitted"** = today's kept master (STACK 2026-11-16a), shown only for contrast — it is in-sample.
- **② FORWARD** = as traded after 2026-11-11 15:11 UTC (DL 527 deploy: B26 paper + B27 live). True "after the CURRENT rule set" is N ≈ 0 for most sleeves (rules changed 11-15 / 11-16).
- **③ BACKTEST** yr6 2-year replay (stack 2026-10-13; lacks every rule from DL ~289 → 567: no RETRY / HT / Flatbase sleeves, pre-V2b WILLY, older ML / LITE exits, none of today's watch filters), 3 seeds.
- **④ LIVE** = B22–B24 LIVE archives + the current live export.
- Stats: avg % with a day-clustered bootstrap 95 % CI, P(avg > 0), days / windows (fills within 30 min = 1 window).

## Recommendation

2. The four refuted sleeves (momentum long / short, FAN flip, FRENZY_LONG): run the sleeve-kill checklist (CLAUDE.md) and decide — the out-of-sample case for them is negative on both the backtest and live.
3. The unproven sleeves: run at a size where one stop costs ≤ 0.5 % of the account, rules frozen, until ≥ 30 forward fills on ≥ 10 days per sleeve give a CI; scale only what clears raw-or-forward CI > 0.
4. Rebuild the 2-year backtest on today's stack (V2b WILLY, LITE +3, RETRY / HT / Flatbase in the replay) — today's Frenzy exits are untested out of sample, the largest blind spot.
